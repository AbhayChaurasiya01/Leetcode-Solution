Welcome to my **LeetCode Solutions** repository! 👋

This repository contains my solutions to **LeetCode problems**, primarily implemented in **Python**. I created this repository to improve my problem-solving skills, strengthen my understanding of Data Structures & Algorithms, and maintain a record of my coding practice.

## 📌 About This Repository

The repository contains solutions to problems from different categories and difficulty levels, including:

* 🟢 Easy
* 🟡 Medium
* 🔴 Hard

Each problem is organized in its own folder using the following naming convention:



Move into the repository:


Open any problem folder and review the solution.
